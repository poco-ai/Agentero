# 配置翻译服务

Agentero 可用不同服务翻译 PDF 中的选区或全文。在 **设置 → 翻译** 中选择默认服务；部分服务需要提供服务商的 API Key、端点和模型。

## 内置模型服务与数据

官方安装包可选择「Agentero 内置」模型服务，无需自行填写 Key。它用于翻译、arXiv 每日推荐的 embedding 和 PDF 正文 OCR；Agent 面板的 ACP 对话使用你连接的 Agent，与这条服务分开。

使用内置服务时，相应内容会发送到内置网关：翻译的选区或全文、用于推荐的库内论文标题和摘要、用于 OCR 的 PDF 页面图。不希望发送时，可在设置里将翻译服务换成免费引擎或已登录的 Agent，将 Embedding 来源切到「自定义接口」并留空，将正文解析引擎切回本地。

内置选项取决于安装包是否在构建时注入凭证。没有凭证的源码构建或 CI 产物会隐藏或禁用该选项；翻译回落免费引擎，正文解析回落本地 liteparse，未配置自定义 embedding 端点时不运行 arXiv 每日推荐。

## 配置 OpenAI 兼容服务

此选项适用于支持 OpenAI Chat Completions 格式的服务。打开 **设置 → 翻译 → API 服务 → OpenAI 兼容**，填写：

| 字段 | 填写内容 |
|---|---|
| API Key | 从服务商控制台获取的密钥 |
| 端点 | 服务的 Base URL，例如 `https://api.openai.com/v1` |
| 模型 | 服务商支持的准确模型 ID |

点击「确定」后，设置页会发送短请求检查配置。通过后，将默认服务切换为「OpenAI 兼容」，再尝试划词或全文翻译。端点也可以填写完整的 `/chat/completions` URL；`/responses` 和厂商自定义文本接口不适用于此处。

密钥应填写在设置页，不要写入 Vault 或提交到 Git。若密钥意外泄露，请在服务商控制台撤销并重建。

### 高级选项

<a id="并发数"></a>
「并发数」控制该服务全文翻译的批次并发，范围 1–8，默认 2；划词翻译不受影响。服务限流时可以调低。

<a id="自动模型适配"></a>
「额外参数」接受 JSON 对象，直接作为请求体参数。留空时应用自动设置采样和思考参数；填写对象后使用该对象替代自动配置，填写 `{}` 则使用服务端默认值。`model`、`messages` 和 `stream` 由应用控制，不能在此覆盖。具体参数请查阅服务商文档，例如：

```json
{
  "chat_template_kwargs": { "enable_thinking": false },
  "temperature": 0.2
}
```

## 无法连接或翻译

1. 检查端点、模型 ID、Key、账号区域与服务商控制台是否一致。
2. 检查账号权限、余额和服务限流；`401` 或 `403` 通常与 Key、区域或权限有关。
3. 检查网络和 **设置 → 通用 → 网络代理**。
4. 设置页检查请求的超时为 5 秒，实际翻译默认 30 秒；服务响应较慢时，短检查可能失败。

服务需返回 `choices[0].message.content` 中的译文，且支持当前非流式请求。服务商接口细节如有变化，以服务商文档为准。

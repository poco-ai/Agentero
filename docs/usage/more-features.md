# 同步、发现与写作

## 同步与备份 Vault

打开**设置 → 同步**，选择对象存储、WebDAV 或 Git，填写对应服务的连接信息后点击**连接**。连接后可以使用**立即同步**，也可以开启自动同步。要在另一台设备使用同一份资料，先备份两端的 Vault，再在另一台设备上连接同一个远端。

同步仅支持本地 Vault。同步范围可以选择是否包含 PDF、LaTeX 源码和支撑材料；笔记、元数据和标注始终参与同步。Git 的排除设置只影响新文件，已被 Git 跟踪的文件仍会同步。Git 同步需要本机安装 Git，并提前配置系统凭据或 SSH 密钥；同步时不会弹出凭据窗口。

两台设备同时修改同一份 Markdown 时，对象存储和 WebDAV 同步会在原文件旁保存冲突副本，需手动核对。Git 使用自己的合并流程，有冲突时会停止同步。同步失败时先检查设置中的状态和错误信息；不要删除冲突文件，确认内容后再处理。

同步不能替代备份：建议定期复制整个 Vault，包括 `.agentero/catalog.sqlite`。如果 PDF 通过软链接存放在 Vault 外，也要单独备份外部文件。对象存储和 WebDAV 的标准同步要求服务端支持条件写入；连接或同步检查失败时，不要假定远端已经保存了全部修改。

## 发现和订阅

从侧栏打开**广场**，可以浏览 Cool Papers 等来源并将感兴趣的论文入库。Library 的 `papers/` 节点右键菜单也提供**发现引用我的新论文**：扫描结束后可以从候选列表中选择要导入的论文。

在侧栏的**订阅**中点击**添加订阅**，粘贴 RSS 或 Atom 地址；也可以添加 arXiv 分区。打开条目查看详情，或使用**入库**保存到 Vault。打开详情会将订阅条目标为已读，也可以筛选已读状态或恢复为未读。

阅读订阅条目本身不会创建 Vault 记录。普通网页入库也不保证正文已经离线保存。X 和 Google Scholar 需要先取得适配器提供的 feed URL。

## 写作项目

在文件树的**写作**下，点击分类旁的加号创建项目，填写名称并选择模板和编译引擎。打开项目后，左侧编辑源码，右侧查看编译后的 PDF。项目文件保存在 Vault 的 `thesis/` 目录中。

正式编译使用本机 `latexmk` 和相应的 LaTeX 引擎。点击预览上方的**编译**生成 PDF；编译失败时，从叹号打开问题和编译日志。需要在源码与 PDF 之间定位时，可以使用两栏之间的定位按钮，或按住 `⌘/Ctrl` 点击 PDF 跳回源码。

项目工具栏的**上传**可以连接已有 GitHub 仓库。每个项目单独使用一个仓库；上传需要本机 Git 和登录凭据，不会替你创建仓库，也不会上传编译产物和 PDF。上传前请确认仓库与项目对应；发生冲突时，应用不会覆盖任一侧的改动。

# 在 iPhone 上使用 Agentero

Agentero iOS 是桌面端的远程客户端。Vault、论文、笔记和 Agent 进程仍保留在已配对的电脑上；手机不创建 Vault，也不运行 ACP Agent。

## 配对电脑

1. 在桌面端打开目标 Vault，进入 **设置 → 远程访问**，开启 Bridge 并显示配对二维码。
2. 在 iPhone 上打开 Agentero，点击 **扫码连接**，扫描二维码。
3. 核对手机和电脑显示的确认码，在电脑上允许配对。

不能使用相机时，可选择 **粘贴配对链接**，粘贴以 `agentero://pair#offer=` 开头的链接。配对成功后，手机进入论文库，以后启动时会尝试恢复连接。

## 阅读与对话

在论文库中可以搜索标题、作者或标识符，打开 PDF，切换到笔记并编辑保存 `NOTES.md`。在 **Agent** 页面可以使用桌面端已配置的 Agent、恢复其支持的历史会话，并处理权限请求。切换 Agent 会重新开始当前移动端草稿。

如果 Agent 列表不完整，在桌面端 **设置 → Agent** 重新扫描和探测，确认 Agent 已注册且显示 ACP ready；必要时重启桌面端 Host 后重新打开手机的 Agent 页面。

## 离线与设备管理

桌面端退出、Bridge 关闭或网络中断时，手机显示离线。PDF 会缓存到手机，离线时只能查看已缓存内容，不能保存笔记或运行 Agent；未完成的写操作不会排队回写。网络恢复后应用会尝试重连。

手机菜单中可查看连接状态、断开或重新配对。新设备首次连接需要在电脑上确认；已配对设备可在桌面端远程访问设置中吊销。手机保存设备密钥、配对信息和可丢弃的内容缓存，Vault 以桌面端为准。Bridge 通过 Relay 转发加密数据，Relay 不解密 Vault 或 Agent 内容。

# 全文译文划选一块一块断开，以及字间更深的一块

**状态**：已修复。英文文字层的划选不改。

## 现象与原因

全文翻译排好版之后，看到的字是一张图。图上面另有一层透明文字，每个汉字一个绝对定位的小框，用来划选。浏览器给每个小框单独铺一层半透明蓝。相邻两个字的框在接缝上叠在一起，叠到的地方颜色更深。英文划选没有这层逐字的框，它把同一行收成一个矩形再画一次。

把这层蓝改成不透明会连图上的字一起盖住，所以不能靠加实色来消掉接缝。

## 修复

- 重排之后的逐字选区不再自己铺蓝色。同一行收成一个半透明矩形，盖在图上，字从下面透出来。接缝只有这一层，不会更深。
- 还没重排、直接盖在原文上的译文同样只留这一条，浏览器选区底色关掉。拖选时不画底下的英文文字层。
- 松手后记入批注的可见范围仍按行并成一条。批注卡片打开、选区本身消失之后，才用这条范围把高亮留在译文上。

## 验证

- `test/pdf-visible-selection-rects.test.ts`：同一行上紧挨着的小块并成一条；下一行，以及同一行上隔得很开的另一栏，保持分开。

# 语音答辩材料被截断

## 现象

答辩准备弹窗最多保留 12,000 个字符，较长的论文笔记会在应用侧被直接截断，可能丢失实验、结论和局限等后半部分材料。

## 原因

早期 MVP 为控制单次 DataChannel 消息大小增加了固定字符上限。该数值不是 ChatGPT Voice 的模型限制，也没有依据材料结构选择保留内容。

## 修复

- 删除自动收集阶段的 12,000 字符切片；
- 删除编辑框输入切片、上限计数和截断提示；
- 材料仍在发送前完整展示并允许编辑；
- 上游存在实际限制时显示真实错误，不在应用侧静默丢弃内容。

## 回归

测试使用超过 12,000 字符且带末尾标记的材料，确认合并结果完整保留末尾内容。

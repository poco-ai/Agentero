# 网页收藏入库（#821）

状态：RSS 右键入库与详情入口已实现（复用现有 URL 导入）；正文归档及统一网页入库用例仍为设计。关联 [#821](https://github.com/poco-ai/Agentero/issues/821)。

## 现有基础

Translator / Connector / Zotero 的 `webpage` 可映射为现有 `PaperKind::Html`，使用 catalog、来源 URL 和 `NOTES.md`；阅读器可以加载远程网页。RSS 有正文抽取与 Markdown 缓存，现可从条目右键菜单 / 详情工具栏提交普通网页 URL 到现有魔棒导入。远程阅读和缓存均不等同于长期归档。

## 目标与边界

让网页与论文一样成为可长期管理的库条目。RSS 是网页入库的一个入口，后续手动 URL / Connector 共用入库用例。复用现有 HTML 类型、`paper_commit`、catalog、笔记和正文抽取能力，不再建立独立的收藏数据库。订阅的已读状态与是否入库相互独立。

## 建议流程

1. 普通 RSS 条目显示收藏入库操作；论文仍走现有论文导入。
2. 确定源 URL，保留用户来源链接；规范化 URL 用于去重（去 fragment / 已知追踪参数，不删除可能影响正文的业务参数）。重定向和 canonical 只在确认内容身份后作为别名，不能任意合并不同页面。
3. 以现有 HTML 类型提交标题、来源、作者 / 日期等可得 metadata；全文抽取复用 RSS 能力并将正文写入 Vault。缓存位置不作为永久引用。
4. 本地正文优先阅读，提供打开原网页；笔记继续使用 `NOTES.md`。再次收藏定位已存在条目，不覆盖用户笔记。
5. 正文抓取失败明确提示未保存全文，允许重试；是否允许仅保存链接需在实现时确定并显示状态。只有提交成功才更新 RSS 入库状态。

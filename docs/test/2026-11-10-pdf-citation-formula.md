# 引用完整性与公式复测

2026-11-10。用户在 **Low-Resistivity Au-Free Ohmic Contacts for Diamond**（`10.1049/ell2.70574`，Wiley/IET，2026）中指出原文引用缺失、组合只显示一篇、`ln(R/r)` 分母丢失，以及 Equation (1)/(2) 在阅读模式下预览错误。本轮按字符、链接和排版结构修复；产品代码不按题名、DOI、文件名或固定页码分支。

本页保留迁移前阶段的历史结果。后续已实现作者年份整组预览及条目跨栏、跨页续接，见 [Wiley 引用完整性回归](2026-11-10-wiley-citation-completeness.md)；当前 0.15.4 包的验收见 [上游迁移试用报告](2026-11-10-upstream-reader-trial.md)。下文“作者年份未整组合并”等描述仅代表当时状态。

此前出版社报告的 118 次悬停主要检查加载和原生目标页，没有逐组核对条目，不能支持“引用完整”或“可交付”的判断。本报告将结构扫描、编号完整性、内容抽查与平台验收分开，不把测试样本通过率外推为任意论文的成功率。

## 修复的通用问题

| 问题类别 | 证据与修改 |
|---|---|
| 字符数组含空槽 | Wiley 第 2 页 4,394 个 glyph 槽中有 268 个空槽。旧代码读取空对象导致整页精细几何失败，原文回退为粗文字行；译文已有完整文本上下文，因而部分引用反而可用。现在跳过空槽但保留原字符索引。 |
| 组合引用只取鼠标下的一项 | 方括号和上标解析保留逗号、区间的完整编号集合；原文、阅读、译文共享解析。每项独立查找和裁剪，支持跨页及非连续组合。 |
| 在线列表次序误当 PDF 编号 | 旧 sidecar 的 `ref-18` 是在线结果第 18 项，却不是 PDF 的第 18 篇，曾显示错误题名。只有明确 `rawKey` 且覆盖整组的 metadata 可抢先展示；其余回到源 PDF 条目。 |
| 异常空白框干扰编号 | 重叠空格不会把 `18` 拆成 `1 8`；高 22pt 的合成空格不会连接相邻三行参考文献。保留真实水平词间空格。 |
| 无标点的上标条目编号 | 使用抬高几何、紧邻作者行、共同栏边界及连续编号确认。独立小文本块形式的 08、11 也可合并；AIP 样本 1–26 的真实目标几何均能匹配。 |
| 多页条目丢失或画错页 | 保留所有命名目标及其页面，即使多个目标坐标冲突；每个裁剪使用自身 pageIndex 和页面尺寸。FitH 的 top 不再当成 left。 |
| 分母归入下一行 | 小号数学字形上下叠置且水平重合时，关联邻近正文尺寸的数学字形所在行，避免把分母归到下一行。修复后实际截图中 `ln(R/r)` 完整。 |
| 公式当成图表或选到页内另一小公式 | 解析通用 `*-disp-N` / `*-fig-N` / `*-tbl-N` 目标模式；公式按原生坐标选择实际区域并局部裁剪。`Table. 1`、`Equation. (1)` 等完整名称后带句点的写法也可识别。 |
| 数学 Unicode 使译文链接偏移 | 旧 `tokenChars` 用 UTF-16 字符串索引切按 Unicode 字符计数的几何数组。前文的 `𝐽`、`𝜑` 等字符占两个编码单元，导致后面 `[27]` 的位置错配。现在每个编码单元对应同一实际字形框；真实原数据与最小回归均先复现失败再验证修复。 |

数字引用部分找到时显示已找到的编号和缺项提示；全部找不到时不展示猜测裁剪。作者年份引用仍按原生 citation key 对应一篇，未实现邻近作者年份组整组合并。

## 特例与剩余限制

- Frontiers 的 `Supplementary Figure S1` 原链接到补充材料下载说明，图不在 PDF；目前没有图预览，点击仍保留原目标。
- PLOS 的 Fig 13 原目标为第 20 页，但实际图在第 22 页；不把第 20 页图 11 冒充图 13。AIP、Oxford 的坏命名目标和 IOP 的错位标注沿用前报告记录。
- AIP 22/23、ACM 23 等裁剪可带入上一条底部的少量笔画；本条完整可读，边缘仍可改善。
- ACM 的重复页眉作者行会混入正文，影响阅读连贯性。没有按作者名特删，仍属待改进的版面角色识别。
- Elsevier 个别独立公式编号仍可能与公式分离；跨页单词、段落断开仍可能出现。历史首字下沉、古老字间距及纯图片 OCR 按当前范围排除。
- 数字区间最多展开 31 个编号，每个编号最多探查八个候选页；超长区间及特殊参考文献组织不承诺恢复。
- 作者年份组不自动合成整组卡；本轮仅验证各原生 citation 对应的单篇。
- 新增预览解析只在文档级缓存及有限页搜索内工作；没有以全篇常驻光栅或增加无界缓存来修复引用。

## 验证、内存与构建交接

最终相关 22 个测试文件：**375 通过、0 失败、3 项可选真实 PDF 测试跳过**。TypeScript `--noEmit` 通过。最小失败回归覆盖空 glyph、组合引用、错误 sidecar 次序、跨页裁剪、异常空格、分母归行、抬高独立编号、完整名称标点、UTF-16 索引。单测不代替桌面验收。

本轮未重复无关的内存压力实验，保留前轮资源优化。WSLg 同负载的隐藏源页单变量对照：未卸载内核最高 RSS 5,236.2 MiB，卸载后 1,886.9 MiB，独立重复 1,933.0 MiB；关闭等待后分别 4,620.0 / 1,057.9 / 1,073.1 MiB。这证明所测条件下改善，不证明长期无泄漏，也不确定历史超限由新功能还是原项目引起。8 GiB 是历史 WebKit footprint 阈值，不是最低内存要求。

    发布前测试大纲（操作 Checklist）¶

    写法：每一行都是 界面 → 操作 → 预期效果。验收时打开应用，按表逐步点选并勾选。
    依据：当前已落地能力（发布线 0.6.0）；不含路线图未交付项（Connected Papers 邻域、引用图反向高亮、Vault 采纳等）。
    环境：至少 macOS；发布含 Windows/Linux 时，§0 + §1 各平台各跑一遍。
    数据：pnpm demo:vault / pnpm demo:vault:downloads；另备一次 Create Vault 空库。

    标记 含义
    ☐ 未测
    ✅ 通过
    ❌ 阻塞发布
    ⚠️ 已知限制，非阻塞（写进 Release notes）
    N/A 本平台/本轮不测
    项 值
    待发版本 / tag
    测试人 / 日期
    阻塞问题

    0. 构建与安装（非 UI）¶

    0.1 版本¶

    # 界面 操作 预期 结果
    0.1.1 仓库 / 终端 对比 package.json、src-tauri/tauri.conf.json、src-tauri/Cargo.toml、cli/Cargo.toml 版本 四者一致，且等于 tag 去掉 v ☐
    0.1.2 应用·设置 / About 打开设置或关于，看版本号 与 tag 一致 ☐
    0.1.3 终端 运行 Release 里的 agentero --version 与 tag 一致 ☐

    0.2 自动化（本机或 CI）¶

    pnpm lint && pnpm test && pnpm build
cargo test --manifest-path src-tauri/Cargo.toml
cargo test -p agentero-cli
    # 界面 操作 预期 结果
    0.2.1 终端 跑上列命令 全部通过 ☐
    0.2.2 GitHub Actions Release job 的 updater secret 校验 TAURI_SIGNING_PRIVATE_KEY 和密码缺失时在创建 Draft 前失败 ☐
    0.2.3 Draft Release 检查 updater 资产 有 latest.json、各平台 updater 包与对应 .sig；latest.json 包含每个平台的 URL 和签名 ☐

    0.3 安装启动¶

    # 界面 操作 预期 结果
    0.3.1 系统 安装本次产物并首次启动 无崩溃、无白屏；进入欢迎页。Linux 在 22.04+ 验收 ☐
    0.3.2 欢迎页 不打开 Vault，空看界面 同一行有 Create / Open / Open remote / Migrate from Zotero + Recent 列表；无大段说明文案 ☐
    0.3.3 设置 → 关于 已安装旧版时检查已发布新版，点「安装并重启」 有新版提示、下载进度；重启后 About 显示新版本 ☐
    0.3.4 主窗口 启动已安装旧版 首屏不阻塞；有新版时只出现一个「安装并重启」Toast；无更新或离线时不弹错误 ☐

    1. 五分钟冒烟（必过）¶

    用全新空目录走通主路径；任一步 ❌ 则阻塞发布。

    # 界面 操作 预期 结果
    1.1 欢迎页 点 Create vault，选空文件夹 进入工作台；左栏出现 papers/ notes/；磁盘有 .agentero/catalog.sqlite、AGENTS.md；无根级 plans/、PAPERS.md ☐
    1.2 中间栏 观察默认中间区 为 Library（可空表或空状态） ☐
    1.3 左栏·树 点魔棒图标，或 ⇧⌘I 打开魔棒弹层 ☐
    1.4 魔棒弹层 粘贴 1706.03762，确认入库 左下角任务条有进度；成功后左栏树展开并滚到新论文行；中间打开该 paper ☐
    1.5 中间栏 看 paper 布局 默认 左 PDF · 右 NOTES（左右分屏） ☐
    1.6 中间栏·NOTES 在 NOTES 打几个字，等自动保存；用外部编辑器打开磁盘 NOTES.md 磁盘内容已更新 ☐
    1.7 左栏·树 点虚拟节点 Library 中间表有刚入库的那一行 ☐
    1.8 系统 完全退出应用再启动 若设置开启「恢复上次 Vault」：直接回到该库；否则欢迎页 Recent 可点回 ☐

    2. 欢迎页与 Vault 切换¶

    # 界面 操作 预期 结果
    2.1 欢迎页 点 Open vault，选已有 Vault（如 demo） 文件树 + Library 加载；无崩溃 ☐
    2.2 欢迎页 点 Recent 里一条本地路径 打开该库 ☐
    2.3 欢迎页 在 Recent 移除一条 条目消失；再次打开欢迎页仍不在 ☐
    2.4 欢迎页 点一条已删除磁盘路径的 Recent Toast 报错；该条从列表剔除 ☐
    2.5 左栏·树顶栏 点 Vault 标题下拉 → Create vault / Open vault… 与欢迎页同类操作，可切换库 ☐
    2.6 标题栏 / 菜单 File → New Window 或 ⌘N 新窗口从欢迎页开始，不自动占用旧窗 Vault ☐
    2.7 两窗口 窗口 A 开库 A，窗口 B 开库 B 互不抢 session；文件树各自独立 ☐
    2.8 欢迎页 （可选）Migrate from Zotero：先建库再选 Zotero 数据目录 迁移对话框可走完；Library 有条目；用户已有 NOTES 不被静默抹掉 ☐

    3. 左栏文件树¶

    前置：已打开 demo 或有内容的 Vault。

    # 界面 操作 预期 结果
    3.1 左栏·树 刚打开库时看默认展开 papers/ 展开（及约定一级）；不会整库无限展开 ☐
    3.2 左栏·树 展开 papers/ 下论文行 标签符合设置（默认「标题 · 作者」）；磁盘文件夹名未改；无附件时无 chevron ☐
    3.2a 左栏·树 打开带 {paper}/attachments/ 文件的论文行 有 chevron；展开后附件直接挂在论文下（不显示 attachments 桶，也不露出 source/ / marks/）；点行仍打开论文 ☐
    3.3 设置 → 通用 改 Paper 行标签 / 排序 各选一档，回看树 展示标签/顺序变了；磁盘路径不变 ☐
    3.4 左栏·树 在 notes/ 右键 → 新建文件，输入名回车 出现新 .md；中间可打开编辑 ☐
    3.5 左栏·树 右键 → 新建文件夹 内联命名成功；树刷新 ☐
    3.6 左栏·树 ⌘ 点多选若干项，拖到 papers/ 某组织夹 文件移入目标；树与磁盘一致 ☐
    3.7 左栏·树 选中文件，右键 在 Finder 中显示 或 ⌥⌘R 系统访达定位到该项 ☐
    3.8 左栏·树 选中文件夹，右键 在终端中打开 或 ⌥⌘T 系统终端 cwd = 该文件夹 ☐
    3.9 左栏·树 选中文件再 ⌥⌘T 终端 cwd = 父目录 ☐
    3.10 左栏·树 选中文件夹，⌘← 该文件夹折叠 ☐
    3.11 左栏·树 ⇧⌘← 折叠回默认（只留 papers/ 等约定展开） ☐
    3.12 中间栏 打开某 paper / md 后看左栏 树展开祖先并滚到对应行 ☐

    3.A 删除与回收站¶

    # 界面 操作 预期 结果
    3.A.1 左栏·树 右键某非关键文件 → 删除（或 ⌘⌫） 无确认框、无 Undo toast；项从树消失 ☐
    3.A.2 左栏·树 点 Library 下 Recycle Bin 中间栏打开回收站列表，可见刚删项 ☐
    3.A.3 中间栏·回收站 点 恢复 文件回原路径；树可见 ☐
    3.A.4 中间栏·回收站 再删一次后点 永久删除 项消失且无法恢复 ☐
    3.A.5 左栏·树 在 Recycle Bin 节点右键 清空 回收站空 ☐
    3.A.6 左栏·树 删除一篇 paper 文件夹 Library 对应行消失；恢复 paper 后 Library 行回来 ☐

    3.B 外部修改与冲突¶

    # 界面 操作 预期 结果
    3.B.1 中间栏·MD 打开某 .md，不做未存编辑；用外部编辑器改磁盘同文件并保存 应用内编辑器自动变成磁盘内容 ☐
    3.B.2 中间栏·MD 打开同文件，在应用内先改几个字（未落盘），再用外部编辑器改磁盘 Toast 提示冲突/重载；不静默覆盖你的未存改动 ☐
    3.B.3 访达 / 终端 在 Vault 外新建或删除一个文件 文件树去抖刷新后反映变化 ☐

    4. 中间栏工作区（Dockview）¶

    # 界面 操作 预期 结果
    4.1 左栏·树 点虚拟 Library 中间全库表；标题栏没有单独文档 tab 条 ☐
    4.2 左栏·树 点一篇 paper 打开 PDF|NOTES 分屏 panel ☐
    4.3 左栏·树 再点另一篇 paper 叠进同一两栏（不强制拆出第三列）；body/NOTES 同步切换 ☐
    4.4 左栏·树 点 notes/ 下某 md、再点一张图、再点任意路径 PDF 各打开对应 panel；切换后滚动/缩放尽量保留 ☐
    4.5 中间栏 对已打开路径的文件再点一次树 聚焦已有 panel，不重复开两个 ☐
    4.6 中间栏 打开设置 ⌘,，再按 ⌘W 或 Esc 先关设置，不关文档 panel ☐
    4.7 中间栏 无弹层时连按 ⌘W 逐个关 panel；只剩全库后再按 → 关窗口 ☐
    4.8 中间栏 开多个 panel 后 ⌥⌘→ / ⌥⌘← 按视觉顺序循环激活 ☐
    4.9 左栏·树 单击 papers/ 下非 paper 的组织文件夹 仍是 Library 表，但只显示该 path 前缀下的论文（不新开 tab、不整库重拉） ☐
    4.9.1 左栏·树 组织文件夹含索引 NOTES.md，且内部有多篇 paper 组织文件夹保持可展开；内部每篇 paper 独立显示，不被合并成父目录 ☐
    4.10 标题栏 Layout 开关 NOTES 相关项 / 快捷键 NOTES 显示或隐藏符合菜单 ☐
    4.11 中间栏 把 panel 拖成上下或左右分屏；从树拖文件到边 多分屏网格可用 ☐
    4.12 左栏 / 右栏 点折叠按钮；交替 ⌥⌘S / ⌘L 侧栏折叠且保留像素宽度；两栏快捷键不「抢成互斥坏掉」 ☐
    4.13 系统 关窗再开同一本地库 布局尽量从 localStorage 恢复 ☐

    6. 入库¶

    6.1 魔棒（精确 ID）¶

    # 界面 操作 预期 结果
    6.1.1 左栏·树 先点选 papers/ 或某子文件夹；打开魔棒 ⇧⌘I 弹层打开 ☐
    6.1.2 魔棒 粘贴 arXiv ID 1706.03762 入库 目标目录下新建论文夹；PDF 在论文根；arXiv 有 source/ TeX；有 NOTES.md 壳；catalog 有行 ☐
    6.1.3 魔棒 粘贴 arXiv URL 再入一篇 同上语义 ☐
    6.1.4 魔棒 粘贴一个可用 DOI 有 catalog 行；尽量有 PDF；失败则 Toast，侧栏无常驻红条 ☐
    6.1.5 魔棒 一次粘贴多个 ID（换行/逗号） 去重后创建对应数量的独立后台任务并并行入库；每个任务显示自己的进度；不会对每篇自动连跑精读 ☐
    6.1.6 魔棒 对已有 NOTES 的 paper 再入同一 ID 不覆盖用户 NOTES.md ☐

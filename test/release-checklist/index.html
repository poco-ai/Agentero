发布前测试大纲（操作 Checklist）¶

写法：每一行都是 界面 → 操作 → 预期效果。验收时打开应用，按表逐步点选并勾选。
依据：当前已落地能力；不含 V0.7 引用图、关键词 Agent 候选、Vault 采纳等未交付项。
环境：至少 macOS；发布含 Windows/Linux 时，§0 + §1 各平台各跑一遍。
数据：pnpm demo:vault / pnpm demo:vault:downloads；另备一次 Create Vault 空库。

标记 含义
☐ 未测
✅ 通过
❌ 阻塞发布
⚠️ 已知限制，非阻塞（写进 Release notes）
N/A 本平台/本轮不测
项 值
待发版本 / tag
测试人 / 日期

0. 构建与安装（非 UI）¶

0.1 版本¶

# 界面 操作 预期 结果
0.1.1 仓库 / 终端 对比 package.json、src-tauri/tauri.conf.json、src-tauri/Cargo.toml、cli/Cargo.toml 版本 四者一致，且等于 tag 去掉 v ☐
0.1.2 应用·设置 / About 打开设置或关于，看版本号 与 tag 一致 ☐
0.1.3 终端 运行 Release 里的 agentero --version 与 tag 一致 ☐

0.2 自动化（本机或 CI）¶

pnpm lint && pnpm test && pnpm build
cargo test --manifest-path src-tauri/Cargo.toml
cargo test -p agentero-cli
# 界面 操作 预期 结果
0.2.1 终端 跑上列命令 全部通过 ☐

0.3 安装启动¶

# 界面 操作 预期 结果
0.3.1 系统 安装本次产物并首次启动 无崩溃、无白屏；进入欢迎页 ☐
0.3.2 欢迎页 不打开 Vault，空看界面 同一行有 Create / Open / Open remote / Migrate from Zotero + Recent 列表；无大段说明文案 ☐

1. 五分钟冒烟（必过）¶

用全新空目录走通主路径；任一步 ❌ 则阻塞发布。

# 界面 操作 预期 结果
1.1 欢迎页 点 Create vault，选空文件夹 进入工作台；左栏出现 papers/ notes/ plans/；磁盘有 .agentero/catalog.sqlite、AGENTS.md；无根级 PAPERS.md ☐
1.2 中间栏 观察默认中间区 为 Library（可空表或空状态） ☐
1.3 左栏·树 点魔棒图标，或 ⇧⌘I 打开魔棒弹层 ☐
1.4 魔棒弹层 粘贴 1706.03762，确认入库 左下角任务条有进度；成功后左栏树展开并滚到新论文行；中间打开该 paper ☐
1.5 中间栏 看 paper 布局 默认 左 PDF · 右 NOTES（左右分屏） ☐
1.6 中间栏·NOTES 在 NOTES 打几个字，等自动保存；用外部编辑器打开磁盘 NOTES.md 磁盘内容已更新 ☐
1.7 左栏·树 点虚拟节点 Library 中间表有刚入库的那一行 ☐
1.8 系统 完全退出应用再启动 若设置开启「恢复上次 Vault」：直接回到该库；否则欢迎页 Recent 可点回 ☐

2. 欢迎页与 Vault 切换¶

# 界面 操作 预期 结果
2.1 欢迎页 点 Open vault，选已有 Vault（如 demo） 文件树 + Library 加载；无崩溃 ☐
2.2 欢迎页 点 Recent 里一条本地路径 打开该库 ☐
2.3 欢迎页 在 Recent 移除一条 条目消失；再次打开欢迎页仍不在 ☐
2.4 欢迎页 点一条已删除磁盘路径的 Recent Toast 报错；该条从列表剔除 ☐
2.5 左栏·树顶栏 点 Vault 标题下拉 → Create vault / Open vault… 与欢迎页同类操作，可切换库 ☐
2.6 标题栏 / 菜单 File → New Window 或 ⌘N 新窗口从欢迎页开始，不自动占用旧窗 Vault ☐
2.7 两窗口 窗口 A 开库 A，窗口 B 开库 B 互不抢 session；文件树各自独立 ☐
2.8 欢迎页 （可选）Migrate from Zotero：先建库再选 Zotero 数据目录 迁移对话框可走完；Library 有条目；用户已有 NOTES 不被静默抹掉 ☐

3. 左栏文件树¶

前置：已打开 demo 或有内容的 Vault。

# 界面 操作 预期 结果
3.1 左栏·树 刚打开库时看默认展开 papers/ 展开（及约定一级）；不会整库无限展开 ☐
3.2 左栏·树 展开 papers/ 下论文行 标签符合设置（默认「标题 · 作者」）；磁盘文件夹名未改 ☐
3.3 设置 → 通用 改 Paper 行标签 / 排序 各选一档，回看树 展示标签/顺序变了；磁盘路径不变 ☐
3.4 左栏·树 在 notes/ 右键 → 新建文件，输入名回车 出现新 .md；中间可打开编辑 ☐
3.5 左栏·树 右键 → 新建文件夹 内联命名成功；树刷新 ☐
3.6 左栏·树 ⌘ 点多选若干项，拖到 papers/ 某组织夹 文件移入目标；树与磁盘一致 ☐
3.7 左栏·树 选中文件，右键 在 Finder 中显示 或 ⌥⌘R 系统访达定位到该项 ☐
3.8 左栏·树 选中文件夹，右键 在终端中打开 或 ⌥⌘T 系统终端 cwd = 该文件夹 ☐
3.9 左栏·树 选中文件再 ⌥⌘T 终端 cwd = 父目录 ☐
3.10 左栏·树 选中文件夹，⌘← 该文件夹折叠 ☐
3.11 左栏·树 ⇧⌘← 折叠回默认（只留 papers/ 等约定展开） ☐
3.12 中间栏 打开某 paper / md 后看左栏 树展开祖先并滚到对应行 ☐

3.A 删除与回收站¶

# 界面 操作 预期 结果
3.A.1 左栏·树 右键某非关键文件 → 删除（或 ⌘⌫） 无确认框、无 Undo toast；项从树消失 ☐
3.A.2 左栏·树 点 Library 下 Recycle Bin 中间栏打开回收站列表，可见刚删项 ☐
3.A.3 中间栏·回收站 点 恢复 文件回原路径；树可见 ☐
3.A.4 中间栏·回收站 再删一次后点 永久删除 项消失且无法恢复 ☐
3.A.5 左栏·树 在 Recycle Bin 节点右键 清空 回收站空 ☐
3.A.6 左栏·树 删除一篇 paper 文件夹 Library 对应行消失；恢复 paper 后 Library 行回来 ☐

3.B 外部修改与冲突¶

# 界面 操作 预期 结果
3.B.1 中间栏·MD 打开某 .md，不做未存编辑；用外部编辑器改磁盘同文件并保存 应用内编辑器自动变成磁盘内容 ☐
3.B.2 中间栏·MD 打开同文件，在应用内先改几个字（未落盘），再用外部编辑器改磁盘 Toast 提示冲突/重载；不静默覆盖你的未存改动 ☐
3.B.3 访达 / 终端 在 Vault 外新建或删除一个文件 文件树去抖刷新后反映变化 ☐

4. 中间栏工作区（Dockview）¶

# 界面 操作 预期 结果
4.1 左栏·树 点虚拟 Library 中间全库表；标题栏没有单独文档 tab 条 ☐
4.2 左栏·树 点一篇 paper 打开 PDF|NOTES 分屏 panel ☐
4.3 左栏·树 再点另一篇 paper 叠进同一两栏（不强制拆出第三列）；body/NOTES 同步切换 ☐
4.4 左栏·树 点 notes/ 下某 md、再点一张图、再点任意路径 PDF 各打开对应 panel；切换后滚动/缩放尽量保留 ☐
4.5 中间栏 对已打开路径的文件再点一次树 聚焦已有 panel，不重复开两个 ☐
4.6 中间栏 打开设置 ⌘,，再按 ⌘W 或 Esc 先关设置，不关文档 panel ☐
4.7 中间栏 无弹层时连按 ⌘W 逐个关 panel；只剩全库后再按 → 关窗口 ☐
4.8 中间栏 开多个 panel 后 ⌥⌘→ / ⌥⌘← 按视觉顺序循环激活 ☐
4.9 左栏·树 单击 papers/ 下非 paper 的组织文件夹 仍是 Library 表，但只显示该 path 前缀下的论文（不新开 tab、不整库重拉） ☐
4.10 标题栏 Layout 开关 NOTES 相关项 / 快捷键 NOTES 显示或隐藏符合菜单 ☐
4.11 中间栏 把 panel 拖成上下或左右分屏；从树拖文件到边 多分屏网格可用 ☐
4.12 左栏 / 右栏 点折叠按钮；交替 ⌥⌘S / ⌘L 侧栏折叠且保留像素宽度；两栏快捷键不「抢成互斥坏掉」 ☐
4.13 系统 关窗再开同一本地库 布局尽量从 localStorage 恢复 ☐

6. 入库¶

6.1 魔棒（精确 ID）¶

# 界面 操作 预期 结果
6.1.1 左栏·树 先点选 papers/ 或某子文件夹；打开魔棒 ⇧⌘I 弹层打开 ☐
6.1.2 魔棒 粘贴 arXiv ID 1706.03762 入库 目标目录下新建论文夹；PDF 在论文根；arXiv 有 source/ TeX；有 NOTES.md 壳；catalog 有行 ☐
6.1.3 魔棒 粘贴 arXiv URL 再入一篇 同上语义 ☐
6.1.4 魔棒 粘贴一个可用 DOI 有 catalog 行；尽量有 PDF；失败则 Toast，侧栏无常驻红条 ☐
6.1.5 魔棒 一次粘贴多个 ID（换行/逗号） 去重后顺序入库；任务条聚合进度；不会对每篇自动连跑精读 ☐
6.1.6 魔棒 对已有 NOTES 的 paper 再入同一 ID 不覆盖用户 NOTES.md ☐
6.1.7 设置 → 通用 把 Translator URL 改成无效地址，再魔棒入库 Toast 失败信息可读；改回默认可恢复 ☐

6.2 本地 PDF¶

# 界面 操作 预期 结果
6.2.1 魔棒弹层 选「本地 PDF / 文件」，多选 2 个 PDF 导入 各生成 papers/<citekey>/，含 PDF + PAPER.md + catalog ☐
6.2.2 访达 把外部 PDF 拖进左栏 papers/ 某组织夹 弹出 metadata 确认框；确认后入库 ☐
6.2.3 同上 再导同名冲突 PDF citekey 带 -2 / -3 等后缀，不互相覆盖 ☐

6.3 补下载¶

# 界面 操作 预期 结果
6.3.1 左栏·树 找缺 PDF 的 paper 行，hover Download 有原因说明 ☐
6.3.2 左栏·树 点 Download 任务条进度；PDF 落地；无 TeX 时生成 PAPER.md ☐

6.4 Zotero Connector（可选）¶

前置：浏览器装官方 Zotero Connector；关掉 Zotero 桌面（端口 23119）。

# 界面 操作 预期 结果
6.4.1 设置 → 通用 打开「兼容 Zotero Connector」 状态为 Listening，且绑定当前 Vault ☐
6.4.2 系统 同时开 Zotero 桌面再开开关 明确端口占用失败提示 ☐
6.4.3 浏览器 打开论文页，点 Connector 保存 Agentero 入库；树/Library 刷新；打开或聚焦该 paper ☐
6.4.4 浏览器 对登录墙 PDF 触发附件保存（若场景可得） 附件进入论文目录 ☐
6.4.5 设置 关闭开关后退出应用 端口释放；浏览器不再认为 Zotero 在线 ☐

7. PDF / 图片 / Markdown¶

建议：demo vault 中的 paper PDF + assets/sample.pdf + assets/figures/*。

7.1 PDF 阅读¶

# 界面 操作 预期 结果
7.1.1 左栏·树 点 paper 下 PDF 或 assets/sample.pdf 中间 blob 预览，非系统外部打开 ☐
7.1.2 中间栏·PDF 底栏改页码 / PageDown / Home 跳页正确 ☐
7.1.3 中间栏·PDF 适应宽度、适应整页、滚轮缩放 重渲染清晰；放大后可平移 ☐
7.1.4 中间栏·PDF 打开大纲，点书签 跳到对应位置 ☐
7.1.5 中间栏·PDF ⌘F 输入文中词 命中高亮；可下一条 ☐

7.2 划词与批注¶

# 界面 操作 预期 结果
7.2.1 中间栏·PDF 拖选一段文字 平滑蓝色选区 + 操作菜单（高亮 / 批注 / 提问 / 翻译） ☐
7.2.2 菜单 选 高亮 高亮保留；磁盘 marks/ 有记录；原始 PDF 字节不变 ☐
7.2.3 菜单 选 批注，写 comment 页边批注针；右侧批注面板有卡片 ☐
7.2.4 右栏·批注 点卡片跳转 / 编辑 / 删除 跳页正确；改删同步 ☐
7.2.5 菜单 翻译 一段 按设置中翻译服务出结果 ☐
7.2.6 菜单 提问（已配 Agent） 进入 Agent 上下文，非静默失败 ☐

7.3 图片与 MD 插图¶

# 界面 操作 预期 结果
7.3.1 左栏·树 点 assets/figures 下 png/jpg 等 中间图片预览 ☐
7.3.2 中间栏·MD 打开笔记，粘贴一张图 磁盘 {mdDir}/assets/ 有文件；正文 ![](./assets/…)；树可见 ☐
7.3.3 中间栏·MD 单击选中图片节点 显示 Markdown 源码而非位图 ☐
7.3.4 中间栏·MD 删除该图片节点（且无其它引用） assets 文件被 GC；树刷新 ☐

8. Markdown、双链、图谱¶

# 界面 操作 预期 结果
8.1 中间栏·MD 编辑标题、列表、代码块、表格，等自动保存 磁盘一致；重启仍在 ☐
8.2 设置 → Appearance 开关 格式工具栏 编辑器顶栏显隐 ☐
8.3 中间栏·MD 写入 [[某已存在笔记]]，点击链接 跳转到目标文件 ☐
8.4 中间栏·MD 写入不存在的 [[新概念]]，走创建入口 可新建目标文件 ☐
8.5 右栏 切到 Backlinks，打开被引用文件 上方列出反链来源 ☐

8.7 中间栏·MD 新增/删除一条 [[链接]]，等约 1s Backlinks/Graph 刷新 ☐

9. 命令面板与快捷键¶

# 界面 操作 预期 结果

11.1 对话¶

# 界面 操作 预期 结果

11.2 权限¶

# 界面 操作 预期 结果
11.2.1 设置 → Agent 权限 = 每次询问；让 Agent 做需授权操作 弹出 Allow once / Always / Reject；拒绝则不执行 ☐
11.2.2 设置 → Agent 权限 = 自动批准；再跑同类操作 不弹窗，直接继续 ☐

11.3 工作流与精读¶

# 界面 操作 预期 结果
11.3.1 右栏·Agent（空态） 点 Summarize / Ask library / Draft Related Work 对当前聚焦 paper 发起对应 workflow ☐
11.3.2 左栏·树 找资源齐全且未读 paper，点 Zap 任务条 paper-reader 进度；写/更新 NOTES.md；is_read 变已读；Zap 消失 ☐
11.3.3 设置 → Agent 打开 入库后自动精读；魔棒再入一篇未读 入库/下载完成后自动精读；任务条可见 ☐
11.3.4 魔棒 批量多 ID 入库（自动精读开着） 不对批量每篇连跑精读 ☐
11.3.5 右栏·Agent 历史 精读跑完后翻主对话列表 精读不出现在主 chat 历史 ☐

11.4 禅模式¶

12. 远程 Vault（macOS / Linux）¶

本轮不测远程则整节 N/A。Windows 只测 12.9。

# 界面 操作 预期 结果
12.1 欢迎页 点 Open remote…，填 host / user / 远端绝对路径，连接 成功则进工作台；树显示远端内容 ☐
12.2 欢迎页 故意填错密码或路径 可读错误；不白屏 ☐

12.5 魔棒 入库一篇到远程库 文件与 catalog 在远端 ☐

12.7 系统 退出再启动，点远程 Recent 需重新 SSH，不能当本地路径直接打开 ☐
12.8 设置 → Agent（远程会话） 远端探测 Agent，发对话 Agent 在服务器跑，cwd 为远端 Vault ☐

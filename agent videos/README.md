# Agentero 视频教程总规划

> 状态：制作规划；基于 2026-09-24 的仓库功能与用户文档。录制每支视频前，以当时的正式安装包复核界面、可用平台与服务状态。
>
> 第一支视频的逐秒脚本：[00-overview-script.md](00-overview-script.md)。

## 目标与受众

这套视频要让没有安装 Agent 的研究者也能开始使用 Agentero，再帮助有需要的人逐步接入 Agent、Zotero 和跨设备工作流。

| 观众 | 推荐观看路径 | 完成目标 |
|---|---|---|
| 第一次使用的研究者 | 总览 → 主线 01–07 | 建库、发现与导入论文、阅读、标注、翻译、整理笔记 |
| 希望让 Agent 参与科研的人 | 上述内容 → 主线 08–10 → Agent 专题 | 接入自己的 Agent，控制上下文与权限，审阅笔记修改 |
| 已有 Zotero 文库或复杂工作流的人 | 总览 → 对应扩展专题 | 迁移、同步、远程访问、CLI 或 MCP |

### 统一叙事

发现论文 → 收进 Vault → 阅读并留下自己的判断 → 与其他论文建立联系 → 按需交给 Agent → 保留可访问、可备份的研究资料。

对外讲解时保持三个概念一致：

- **Vault**：保存论文、笔记和标注的普通文件夹。
- **Library**：基于 Catalog 的论文列表；论文正文与笔记仍以 Vault 中的文件为准。
- **Agent**：由用户自行安装和登录，通过 ACP 接入应用内对话；无需 Agent 也能使用阅读与笔记工作流。正式安装包中的内置模型服务用于翻译、推荐 embedding 和 PDF 正文 OCR，不提供应用内 ACP 对话。

本地优先不等于所有能力都离线。讲到内置翻译、推荐或云端解析时，应交代相应内容会发送到所选服务。

## 课程结构与观看顺序

采用 **1 支总览片 + 10 集主线 + 约 20 支扩展片 + 按真实问题补充的短答疑**。总览片建立印象；主线从零完成一次研究任务；扩展片可以按需跳看。扩展编号 E18 分成 MCP 与 CLI 两支发布，另有创作工具短片，因此实际发布数量约 20 支。

### 00 总览片

**《Agentero 是什么？从找到论文到形成研究笔记的一套工作台》**，目标 4–6 分钟。只回答产品解决的问题、完整工作流长什么样、无 Agent 能做什么、不同观众从哪集开始。不要把安装步骤塞入总览。详见[逐秒脚本](00-overview-script.md)。

### 主线：从零完成一次研究任务

| 集数 | 建议标题 | 时长 | 观众完成标志 |
|---|---|---:|---|
| 01 | 安装、首次引导、创建第一个 Vault | 8–10 分钟 | 有自己的 Vault；认清工作台与自带教程笔记；知道 Agent 步骤可跳过 |
| 02 | 把第一篇论文导入 Agentero | 8–12 分钟 | 本地 PDF 与 DOI/arXiv/标题至少各演示一种入库方式；看懂后台任务与补下载 |
| 03 | 把 Library 整理成自己的文献库 | 8–10 分钟 | 会搜索、排序、加标签、组织文件夹、编辑元数据、调整列、从回收站恢复 |
| 04 | 读 PDF：导航、高亮和批注 | 8–12 分钟 | 会用大纲、搜索、页码、缩放、高亮、页边批注；知道标注不改原 PDF |
| 05 | 读外文论文：划词、单页和全文翻译 | 8–10 分钟 | 完成划词与全文翻译，知道服务选择和联网边界 |
| 06 | 写一份以后还看得懂的 NOTES.md | 10–12 分钟 | 写下问题、方法、局限和个人判断；用属性、图片、双链并导出笔记 |
| 07 | 从一篇论文找到下一篇 | 8–12 分钟 | 用广场、References 和文中引用找到并入库一篇相关论文 |
| 08 | 从零接入自己的第一个 Agent | 10–15 分钟 | 完成一个真实 Agent 的安装、登录、ACP 探测和首次提问 |
| 09 | 让 Agent 带着正确上下文读论文 | 10–12 分钟 | 会添加论文/选区/文件上下文，控制权限并审阅笔记改动 |
| 10 | 完整实战：从选题线索到可复用笔记 | 12–18 分钟 | 不间断走完发现、入库、阅读、笔记、关联、Agent 辅助与复查 |

主线 01–07 是无需 Agent 的路径；08–10 才把 Agent 加入已有工作流。每集开头展示最终成果，结尾给观众一个可以自行检查的完成标志。

### 短答疑：根据反馈录

| 编号 | 用户会搜索的问题 | 展示的检查路径 |
|---|---|---|
| Q01 | 导入成功却没有 PDF，或标题识别错了 | 后台任务 → 补下载 → 编辑元数据 → Rescan |
| Q02 | 终端能用 Agent，Agentero 却找不到 | 安装/登录 → ACP 探测 → 路径 → 知识库诊断 |
| Q03 | 翻译、版面分析或更新失败 | 所选服务 → 网络代理/诊断 → 关于页更新与日志 |

答疑片以实际报错和评论为依据，不提前录一整套假设性故障。

## 制作标准

1. **一集解决一件事**：每集写明目标观众、前提、可见成果和一个常见失败入口。扩展片允许观众不看其他扩展就能跟做。
2. **统一演示资料**：准备一份独立演示 Vault、两到三篇可公开演示的论文、预写少量个人笔记。每集从演示 Vault 的副本录制；不要暴露真实私人资料、凭据和通知。
3. **录正式安装包**：录制前复走一遍操作，记录应用版本、操作系统及联网/Agent 前提。源码构建与官方包的内置服务可用性不同。
4. **等待与失败真实呈现**：可以剪短下载/解析/Agent 等待，但保留任务状态并标注时间；使用真实功能结果，不用合成成功状态。
5. **可检索**：标题写观众要完成的任务；简介放对应文档、版本与下一集链接；长片加章节和字幕。
6. **复用与维护**：主线优先保持稳定；MCP、云服务、外部 Agent 安装等容易变化的步骤放独立专题，版本变化时只需替换对应片。

## 发布顺序

| 批次 | 内容 | 验收 |
|---|---|---|
| 第一批 | 总览 + 主线 01–06 | 找一位从未用过 Agentero 的人，仅靠视频完成建库、导入、阅读和笔记 |
| 第二批 | 主线 07–10 + E06/E07/E11/E13 | 两类观众分别能完成 Zotero 或 Agent 的接入 |
| 第三批 | 其余扩展及真实问题答疑 | 根据评论、文档访问和视频留存决定先后 |

发布后重点看总览与 01 集开头 30 秒的留存、观众在哪个操作段跳出、评论重复问什么。视频章节和系列播放列表可帮助观众在完整课程中定位内容。

# 第 00 集：Agentero 总览视频录制脚本

> 视频定位：整套教程的入口；先让陌生观众理解产品与观看路径。它是产品总览，不承担安装教学。
>
> 工作标题：《Agentero 是什么？从找到论文到形成研究笔记的一套工作台》
>
> 目标成片：**5 分 30 秒（330 秒）**，剪辑允许上下浮动 15 秒。画幅 16:9；中文配音；以桌面屏幕为主，不需要出镜。

## 1. 拍完后观众应该知道什么

1. Agentero 把论文发现、入库、阅读、标注、笔记与 Agent 协作放在同一个工作台。
2. 没有安装 Agent，仍能创建 Vault、管理论文、阅读、翻译与记笔记。
3. Vault 是普通文件夹；Library 是论文列表；应用内 Agent 需要用户自行安装、登录并通过 ACP 接入。
4. 观众看完知道自己下一步该看第 01 集、Agent 主线，还是 Zotero 等扩展专题。

不要在本片逐页讲设置、演示 Agent 安装命令、介绍 MCP/CLI 的协议细节。详细操作放在后面的专门视频。

## 2. 本片要用的一套真实演示资料

录制前建一份**独立的演示 Vault**，不要使用私人研究库。建议在正式桌面安装包中使用同一套中文界面与同一款主题完成所有镜头。

| 准备物 | 最低要求 | 用途 |
|---|---|---|
| 演示论文 A | 可公开展示、PDF 有可选文字层，最好有图与参考文献；正式录制时才导入 | 从发现/导入一路贯穿到阅读、翻译、References |
| 演示论文 B | 与 A 有明确关系，录制开始前已导入 Vault | 双链、相关论文与 Library 镜头 |
| 演示笔记 | A 导入后写 3–4 个小标题和几句自己的判断 | 展示最终成果；保留一个空段用于录入新句子 |
| Agent | 一个已安装、登录且在 Agentero 中显示 ACP ready 的真实 Agent | 录制 200–245 秒的短镜头；不要现场安装 |
| 广场/导入 | 至少一篇实际可在 Cool Papers 或魔棒中找到的公开论文 | 录制发现与入库镜头 |
| 桌面文件夹 | 可以在文件管理器中展示演示 Vault 的 papers/、notes/、NOTES.md 和 PDF | 解释数据归属 |

可以选一篇自己熟悉的开放获取论文作为 A；具体论文以你能稳定复现导入、翻译和引用结果为准。不要为了熟悉的论文名牺牲可录性。需要真实 Agent 回答时，预先试问一句简短的问题，例如“这篇论文的主要方法是什么？请指出依据所在章节。”只录实际出现的回答，不制作假的成功界面。

**素材状态安排：** 先在演练 Vault 中测试 A 的导入、翻译、References 与 Agent。正式录制时，另建一份只含 B 的演示 Vault，先拍 A 的入库镜头；随后在这份 Vault 中准备 A 的笔记和标注，再拍阅读、Agent 与开场完成态。录入前保留一份 Vault 副本，便于重拍导入。

### 开录前验收

- [ ] 正式安装包与演示 Vault 可以正常打开，画面显示应用版本。
- [ ] 论文 A 的 PDF 可翻页、划词；翻译服务已在这台机器上实际成功过一次。
- [ ] References 能显示可录的卡片；若无法稳定取得，改录 B 的双链与 Library 跳转，不在旁白中声称当场解析成功。
- [ ] Agent 已登录、探测就绪，能够对 A 回答一次问题；若无法接通，先解决再拍 Agent 镜头。
- [ ] 笔记、文件路径、账号名、通知、浏览器标签和 API Key 已检查，没有私人信息。
- [ ] 保留演示 Vault 的副本；每次重录从同一状态开始。

## 3. 逐秒成片脚本

**读法：** “旁白”可直接照念；“录什么”是屏幕动作；“剪辑”是后期要加的字幕或画面处理。时间是成片位置，不要求按这个顺序现场操作。旁白语速约每秒 3 个汉字；每段给画面留 1–3 秒呼吸，不要一直说话。

### 00:00–00:15｜开场：问题与承诺（15 秒）

**讲什么：** 研究资料分散，先提出观众熟悉的问题。

**录什么：** 先用一张干净的示意画面表现“PDF、笔记、AI 讨论”三个分开的窗口或卡片；随后切到 Agentero 中同一篇论文的完整工作区。这里可以只录真实桌面窗口，三张卡片由剪辑软件加文字。

**旁白：**

> “读论文时，PDF、笔记和 AI 讨论散在不同地方。过几周再看，最难找的往往是当时自己的判断。”

**剪辑：** 第 1 秒就出现论文画面，然后快速切到分散的卡片。屏幕文字只保留“论文 / 标注 / 笔记 / Agent”，不要先播放 logo 动画。

### 00:15–00:35｜一句话说清 Agentero（20 秒）

**讲什么：** 给观众一个产品全貌和最终成果。

**录什么：** 展示 A 已打开的 PDF 与 NOTES.md 分屏，左侧 Library/文件树、右侧可展开的面板短暂停留。鼠标从论文标题移到笔记标题，停住 2 秒。

**旁白：**

> “Agentero 是一个本地优先的文献阅读工作台。你可以在这里收论文、读 PDF、做批注、写笔记；如果已经有自己的 Agent，还可以让它带着当前论文的上下文一起工作。先看一遍完整流程。”

**剪辑：** 角标：“一篇论文 → 一份能继续使用的研究笔记”。

### 00:35–01:15｜发现与导入（40 秒）

**讲什么：** 从外部来源看到论文，到进入自己的文献库。

**录什么：**

1. 在左侧打开广场里的一个真实来源，停在目标论文卡片或列表行。
2. 点击该论文的入库入口，或切到已准备好的魔棒输入 DOI/arXiv ID 镜头。
3. 保留后台任务的开始与完成状态。
4. 切到 Library，搜索并打开这篇论文。

**旁白：**

> “找论文可以从广场的论文来源开始，也可以直接粘贴 DOI、arXiv 编号或论文标题。确认入库后，Agentero 会建立论文条目，并尽量取得 PDF 和可读的正文。它会出现在 Library 里；需要继续下载或识别的部分，可以在后台任务中看到。”

**剪辑：** 网络等待可跳切，但要先后展示任务状态。不要用“任何论文都能一键下载 PDF”作为承诺。屏幕角标：“发现 → 入库 → Library”。

### 01:15–02:00｜阅读、标注与翻译（45 秒）

**讲什么：** 阅读器解决的实际动作。

**录什么：**

1. 打开 A 的 PDF，点一次大纲或搜索，跳到预先选好的页。
2. 选中一小段有意义的句子，创建一条高亮。
3. 打开或点到这条高亮的页边评论，输入一句自己的判断。
4. 再选一小段，显示真实翻译结果；若全文翻译演示过于慢，插入预录的已完成译文覆盖镜头。

**旁白：**

> “读的时候，我可以像普通 PDF 阅读器一样搜索、跳页和看大纲。重要的句子先高亮，再写下我为什么觉得它重要。碰到读不顺的段落，可以划词翻译，也可以对整页或整篇做翻译。标注会跟着这篇论文保存，原始 PDF 不会被直接改写。”

**剪辑：** 镜头聚焦鼠标和结果，界面文字要能看清。翻译角标：“所选服务可能需要联网”；服务选择与数据发送范围留到第 05 集/E13 详讲。

### 02:00–02:40｜把阅读变成笔记（40 秒）

**讲什么：** 临时标注与长期判断之间的关系。

**录什么：** 切回 A 的 PDF / NOTES.md 分屏。在笔记里输入一句新的个人判断；展示“问题、方法、局限、与我的研究的关系”四个小标题。随后点一个指向 B 的双链，再返回 A，或展示笔记中已经存在的相关链接。

**旁白：**

> “高亮提醒我当时看到了什么，真正值得以后复用的结论，我会写进右边的 NOTES。这里是普通 Markdown 文件，可以记录论文解决的问题、方法、局限，以及它和我自己研究的关系。遇到相关论文，还能用双链把两份笔记连起来。”

**剪辑：** 打字镜头只保留一两句，不要让观众看着你打完整篇笔记。屏幕角标：“留下自己的判断”。

### 02:40–03:20｜沿着引用继续研究（40 秒）

**讲什么：** 一篇论文如何带出下一篇。

**录什么：** 在 A 的右侧切到 References；点击一条已核实的参考文献，展示卡片或跳到文中引用；再展示已入库的 B，最后回到 Library 的两篇论文列表。若 References 当天不可复现，用 A 笔记的双链进入 B，再在 Library 搜索 B。

**旁白：**

> “读完一篇通常不是结束。References 能让我检查它引用了哪些工作，已经在库里的论文可以直接打开，想继续读的也能收进来。再加上自己的双链和标签，零散的阅读会慢慢变成一条能回头追溯的研究线索。”

**剪辑：** References 和 Markdown 双链是不同关系，不要把两种图混剪成同一个功能。屏幕文字：“论文引用 / 自己的笔记关联”。

### 03:20–04:05｜Agent 是可选增强（45 秒）

**讲什么：** Agent 能做什么，以及新用户最容易误解的前提。

**录什么：** 打开右侧 Agent 面板，展示当前论文上下文 chip，发送预先试过的问题；切入这次真实回复的一小段。如果已经准备好安全的笔记修改案例，可以快速展示审阅界面，但本段不要求让 Agent 当场改文件。

**旁白：**

> “如果我已经安装并登录了一个支持 ACP 的 Agent，就可以把当前论文或选中的段落交给它，让它解释方法、比较相关工作，或者帮我整理笔记。我仍然要核对它的回答和文件修改。这里的 Agent 用的是我自己接入的助手；没有安装 Agent，前面这些导入、阅读、翻译和记笔记的流程也都能先用起来。”

**剪辑：** 用角标明确写“Agent 可选；应用内对话需要自行接入 ACP Agent”。不要把内置翻译服务的画面接在 Agent 对话上，造成“自带聊天 Agent”的误解。

### 04:05–04:40｜数据放在哪里（35 秒）

**讲什么：** 解释“本地优先”为什么对科研资料重要。

**录什么：** 从 Agentero 切到文件管理器，展示演示 Vault 里 papers/、notes/，进入 A 的目录，显示 PDF 与 NOTES.md；回到应用 Library。不要打开或编辑 catalog.sqlite。

**旁白：**

> “这些资料围绕一个 Vault 组织。Vault 就是电脑上的普通文件夹：PDF、Markdown 笔记和阅读标注都能在里面找到；Library 则帮我浏览这些论文及其元数据。离开 Agentero，我仍能用自己熟悉的工具访问文件。需要联网的翻译或解析服务，会在对应专题里讲清选择和数据范围。”

**剪辑：** 叠加简图“Vault：文件夹和原始资料 / Library：论文列表”。不要说“所有功能完全离线”。

### 04:40–05:15｜告诉不同观众从哪里开始（35 秒）

**讲什么：** 把总览变成课程入口。

**录什么：** 回到 Agentero 完整工作区；用后期文字卡依次显示三个观看路径。不需要在桌面里翻文档页面。

**旁白：**

> “如果你从没接触过 Agent，下一集就从下载安装到第一篇论文开始，一路看到阅读和笔记；这条路径不要求先配置 AI。已经有 Zotero 文库，可以直接看迁移专题。想让 Agent 帮你读和整理，先走完基础流程，再从接入 Agent 的课程开始。”

**剪辑：** 三个卡片：“新用户：01–07 / Zotero 用户：E06–E07 / Agent 用户：08–10”。如果发布时后续视频尚未上线，卡片改写为“即将更新”，不要放空链接。

### 05:15–05:30｜结尾（15 秒）

**讲什么：** 一个明确的下一步。

**录什么：** 用 A 的 PDF 与笔记分屏作结束画面，鼠标停在 Library 或 Vault 名称附近；留空间给下一集的片尾链接。

**旁白：**

> “这就是 Agentero 的基本用法。下一集，我们从一台刚装好软件的电脑开始，建出第一个真正能用的文献库。”

**剪辑：** 片尾只放“下一集：安装与创建 Vault”及对应链接；不要塞满所有社交账号。

## 4. 录制顺序：新手照着做

现场不必按成片顺序录。建议分 **10 个素材片段**，一段错了只重录这一段：

| 素材名 | 先录的内容 | 建议原始素材长度 |
|---|---|---:|
| A01-workspace | 完整工作区慢速展示 | 25–35 秒 |
| A02-discover | 广场中的目标论文 | 15–25 秒 |
| A03-import | 魔棒或广场入库、后台任务 | 30–60 秒 |
| A04-library | Library 搜索并打开论文 | 15–25 秒 |
| A05-read | PDF 搜索/大纲、高亮、批注 | 45–75 秒 |
| A06-translate | 划词翻译或已完成的全文译文 | 20–45 秒 |
| A07-notes | 笔记编辑与双链 | 45–60 秒 |
| A08-references | References 与下一篇论文 | 30–45 秒 |
| A09-agent | 上下文 chip、提问、真实回答 | 45–90 秒 |
| A10-vault | 文件管理器展示 Vault，然后回应用 | 25–35 秒 |

**操作步骤：**

1. 先用演练 Vault 逐项核对第 2 节的开录验收。打开正式桌面 App，选择固定主题、语言和窗口大小。需要下载或模型加载的功能先预热。
2. 另建只含论文 B 的录制 Vault，并备份此时的状态。先录 A02、A03，将 A 真正导入，再录 A04。
3. 给 A 准备少量笔记、标注和双链；接着录 A05、A06、A07、A08、A09、A10。最后录 A01 的完整工作区，作为成片开头和结尾使用。
4. 每次点按钮前停约 1 秒，完成后停约 2 秒。鼠标移动慢而直接；不要在画面里来回找入口。
5. 素材录完才按第 3 节录旁白。读错一句停两秒，重新读该句，后期可根据停顿切开。
6. 以旁白为主线剪画面，先确保 330 秒内逻辑顺，再补字幕、角标、箭头和音乐。不要先做复杂动效。

如果担心旁白配不上画面，先拿手机录一遍完整口播作“节奏草稿”，用它决定每个镜头要录多长；正式旁白可以在粗剪后重录。

## 5. 第一次用 OBS 的最简设置

1. 安装并启动 OBS Studio，运行“自动配置向导”，选择以录制为主。官方[快速入门](https://obsproject.com/kb/quick-start-guide)也建议先运行向导，再做数分钟测试录制。
2. 新建一个“Agentero 总览”场景，添加显示器捕获或窗口捕获。首次制作若需要切到系统文件管理器，使用显示器捕获更省事；录前关闭通知并清理桌面。
3. 选择正确的麦克风，让 OBS 音量表在说话时有变化；如果没有需要保留的应用声音，把桌面音频静音，避免提示音盖住旁白。
4. 画布设为 1920×1080，30 fps。应用窗口尽量占据画布主体，使 PDF 正文和按钮在压缩后仍能辨认。字体太小时先调应用的 UI 缩放，不要依赖后期不断局部放大。
5. 录制格式优先 MKV；后期软件需要 MP4 时在 OBS 中转封装。OBS [录制格式指南](https://obsproject.com/kb/standard-recording-output-guide)说明了这个选择和转封装方法。
6. 先录 2 分钟测试：看画面是否裁切、鼠标是否可见、文字能否读清、旁白是否清晰、切到文件管理器时是否仍被捕获。通过后才正式录 A01。

第一次录制无需摄像头、绿幕、直播插件、多机位或复杂转场。让观众看清操作、听清你为什么这样做，就已经达到本片目标。

## 6. 剪辑与发布检查

### 粗剪

- 先把旁白放在时间线上，按第 3 节的时间段排列真实录屏。
- 剪掉鼠标找按钮、长时间等待与重复操作；下载/解析等待保留开始和结束状态，可用文字写“等待后台任务完成”。
- A01–A10 素材各只承担一种信息，别把页面切换剪得快到看不清当前在哪个区域。
- 每一处功能陈述都回看画面验证；特别检查导入资源、References、翻译和 Agent 回答是否来自实际操作。

### 精剪

- 自动字幕生成后逐句校对产品名、Vault、Library、NOTES.md、ACP、DOI、arXiv。
- 首次出现 Vault、Library、Agent 时加一行短解释；此后用原词，不反复解释。
- 片头 15 秒就交代观众能得到什么。YouTube 的[单视频留存报告](https://support.google.com/youtube/answer/9314415)会显示前 30 秒和各段落的流失，可据此改开场与节奏。
- 全片响度保持一致，音乐只作很低的底色；读论文的画面宁可安静。
- 结尾留 10–15 秒给下一集跳转，导出后再完整看一遍手机尺寸预览。

### 发布信息模板

- **标题**：Agentero 是什么？从找到论文到形成研究笔记的一套工作台
- **简介开头**：本片带你认识 Agentero 的完整文献工作流。无需预装 Agent，也可以先完成导入、阅读、翻译与笔记。
- **简介随后**：放官方下载入口、文档入口、所录应用版本/系统、主线 01 链接、各扩展视频链接。
- **章节**：00:00 痛点与目标；00:35 发现和入库；01:15 阅读标注与翻译；02:00 笔记；02:40 相关论文；03:20 Agent；04:05 Vault 与数据；04:40 从哪集开始。YouTube 手工章节需从 00:00 开始，至少三个递增时间点，详见[官方规则](https://support.google.com/youtube/answer/9884579)。
- **封面**：一张清晰的 PDF/NOTES 分屏截图，加一句短标题，例如“论文读完，笔记留下”。不要把十几个功能都写在封面上。

## 7. 本片的真实性与版本检查

录制前再核对一次：

- Agentero 不捆绑应用内 ACP Agent；它要由用户安装、登录和接入。内置模型服务不等于内置聊天 Agent。[用户指南](../docs/usage/index.md)
- PDF 标注保存在 marks/，不改写原始 PDF；长期结论应写入 NOTES.md。[阅读指南](../docs/usage/read-and-organize.md)
- 正式安装包与源码构建的内置服务可用性不同；相应翻译/解析可能向所选服务发送内容。[内置服务](../docs/backend/builtin-provider.md)
- 当前广场来源、设置入口、快捷键和安装界面可能随版本更新；录正式画面前以正在发布的版本复走脚本。[广场来源](../src/lib/plaza/sources.ts)、[设置导航](../src/components/settings/settings-content.tsx)

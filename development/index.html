开发¶

开发分区说明 Agentero 要构建什么、当前完成了什么、还剩什么，以及发布和文档如何维护。

技术与流程选型¶

领域 选型 原因
产品文档来源 docs/development/ 下的 Markdown 需求和路线图可以在 Git 中 review、追踪和重构。
应用包管理 pnpm 快速、基于 lockfile 的 Node 依赖管理。
TypeScript 质量 Biome 前端代码与文档相关文件的格式化和检查。
Rust 质量 cargo fmt + cargo clippy Rust 官方格式化与 lint 工具。
桌面构建 Tauri CLI 本地和 CI 中构建桌面应用。
发布 CI GitHub Actions + tauri-apps/tauri-action v* tag 触发 macOS、Linux、Windows 安装包构建。
文档站 MkDocs + Read the Docs 主题 静态文档部署到 gh-pages 分支。

当前实现状态¶

区域 状态 摘要
V0.1 工作台 ✅ 文件树（Finder / 回收站 / 多选拖拽）、Markdown IO + 内嵌图、文件监听、Library + tags + Rescan、多窗口、catalog、后台任务条、全局 Toast
V0.2 标识符入库 🟡 精确路径 ✅ 魔棒 + Translator、catalog 权威、默认 PDF + arXiv TeX、单篇/Library 补下缺失；关键词 Agent 候选与 export 仍待
V0.3 Agent 🟡 BYOA + ACP / Codex 原生 runtime、流式 UI、Sources、paper-reader（Zap + 可选自动默认关）、权限三档（含每次询问）、面板 workflow、笔记写后审阅；AGENTS.md 注入仍待
V0.4 双链/图谱 ✅ Backlinks + Graph 同栏；graph_get_graph；文件变更防抖重建索引
阅读增强 🟡 任意路径 PDF/图；导航·适应整页·大纲·⌘F·真实 scale·平滑划词；划词菜单 MVP；highlights.md 导出仍待
翻译服务 ✅ 首版 应用级可插拔 TranslateService（free + BYOA Agent，无付费 API）；设置 → 翻译；见 translate.md
V0.5 Importer ⏳ 本地 PDF / PdfParser 规划中
V0.6 标签页与分屏 🟡 标签页 ✅ 文档标签页已落地（⌘W 关 tab / 无 tab 关窗）；分屏（split） 仍待
V0.7 引用关系 ⏳ Connected Papers 式邻域、文内引用 hover→Info、引用 Agent 工作流（规划中）
CLI headless ✅ MVP cli/ + workspace；agentero bin；Vault/catalog/import/export/paper set-tags；无 BYOA（见 cli.md）
Vault 采纳 ⏳ 打开已有文件夹时自动发现/整理；编程 + 可选 Skill（见 roadmap）
Zotero Connector 兼容 ✅ MVP 本机 23119：saveItems + 子文件夹 targets + saveAttachment；设置开关默认关；见 ../backend/connector.md
全库搜索 / 命令面板 ✅ Phase A ⌘P/⌘K 快速打开 + ⇧⌘P 命令模式；> 前缀；见 command-palette.md
应用弹层栈 ✅ overlay-stack：Esc/⌘W 统一关最顶层 sheet/Dialog；见 ../frontend/ui.md §3.0
Release CI ✅ v* tag → 三平台桌面安装包 + CLI agentero 预编译包（同草稿 Release）

更细的勾选表见 roadmap.md；可执行任务见 todo.md。

本分区文档¶

  • prd.md：产品需求、范围、用户流程、验收标准。
  • roadmap.md：状态快照、完成项和优先级路线图。
  • todo.md：按 P0/P1/P2 拆分的可执行 backlog。
  • github-project.md：GitHub Project「Agentero」结构、标签、Issue 映射（B1–B8 / F1–F18 → #7–#32；B2/B4–B8 已关闭；#33 非 Codex 历史；看板 orgs/poco-ai/projects/1）。
  • bug.md：已知 bug / UX 语料与勾选状态（与 GitHub B1–B8 对齐）。
  • technical-plan.md：跨前后端的技术方案和模块设计。
  • cli.md：CLI 语义与技术栈——目录 cli/，不迁 core，path 依赖 agentero_lib；Vault 管理/发现/暴露 + 文献基础；无 BYOA；Agent 友好 JSON（MVP 已落地）。
  • pdf-ask.md：PDF 划词提问（MVP 已落地；选区/双击/悬停 → 迷你问答 → JSON → 锚点图标）技术栈与数据契约。

  • logging.md：运行日志（P0 已落地；tauri-plugin-log + log + CLI env_logger；关键操作 start/end；与 Toast / ApiResult 分层）。
  • command-palette.md：全局命令面板 / 快速打开（对照 VS Code ⇧⌘P · ⌘P；现状与分期设计）。
  • bug.md：待处理现象语料（与 Project / Issue 草案对照）。
  • .md：简短产品假设。
  • Bug 修复记录：../bug_fix/deepseek-thinking-body.md（DeepSeek 正文落入 Thinking）。
  • Paper 入库流水线统一：../backend/paper-import-pipeline.md。

一、论文入库与 PDF 处理¶

  • 重构 paper 入库流程
  • 本地 PDF 导入时 metadata 与 note.md 初始化未做
  • 拖入本地 PDF 会直接跳 PDF 预览器并卡死
  • Note MD 在下载有问题时初始化有问题

二、Agent / 对话¶

  • 当前论文默认加到对话当中
  • Update 时也要更新 skill 文件夹下 skill 是否最新
  • 在根目录下放一个 chat 文件做全局对话/对话历史记录（需开 issue 讨论）
  • 加用户可定义系统提示词插入

三、Markdown 编辑器¶

  • Markdown 编辑器编辑时卡顿
  • 选中文字为什么是蓝色
  • 各种功能都需要改进
  • 点不到最后一行，不能换到新的一行
  • 笔记改动页面用 Diff 格式，不要使用对比，看不清楚

四、文件树 / Vault¶

  • [x] 侧边栏在对话的时候。@ 需要给最近目录或目录树提示
  • [x] 侧边栏在对话的时候 @ 需要和文件树一样把文件名改成论文名，保持和设置当中一样的
  • [x] 文件夹排序应按目录树中显示名称排序，而不是原目录文件夹名
  • [x] 目录树收缩节点需要快捷键，折叠至默认只展开 papers/、不展开其子目录（⌘← 折叠选中 / ⇧⌘← 折叠至默认）

五、批注 / PDF UI¶

  • 批注默认文字颜色太深
  • 批注应该有 Enter 快捷键

六、界面 / 图标¶

  • 整体页面 icon 偏小，小屏幕下更小
  • 配置「面板」的 Icon 换新的，和另一个太像
  • [x] 热力图标在标题文字背景上（横条左→右 = 文首→文末，深度 = 该位置交互强度；颜色不显眼）
